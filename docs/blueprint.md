# **App Name**: Fanan Team Hub

## Core Features:

- Main Pages: Display main pages: Home, Contact Us, GUI Me, How to Buy, Buy Now.
- Product Page Display: Product page layout: large image, thumbnails, description, price, download links, and demo limitations.
- Template Builder Assistance: AI-powered form tool that assists in building product pages using a template.
- Management Page: Management page to add and manage product pages.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) for a sophisticated and technological feel.
- Background color: Light gray (#F0F0F0) to provide a clean and neutral backdrop.
- Accent color: Electric blue (#3F51B5) for interactive elements and important callouts.
- Font pairing: 'Poppins' (sans-serif) for headlines, 'PT Sans' (sans-serif) for body text.
- Use simple, modern icons to represent product categories and functionalities.
- Clean and organized layout with clear sections for images, descriptions, and purchase options.
- Subtle transitions and animations for loading content and user interactions to enhance engagement.
